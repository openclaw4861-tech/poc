Pacific Glazing Corporation — Internal Briefing August 12, 2026 Prepared for: Steve Watts, CEO

1. Executive Summary

The open-source AEC software stack has reached a decisive inflection point this week: three core capabilities—IFC parsing, browser-native BIM review, and survey-grade photogrammetry—are now production-grade infrastructure available at zero licensing cost. The most significant development for PGC is that browser-based markup and review can now displace Bluebeam entirely for submittal workflows, eliminating per-seat licensing while removing version-control friction. Meanwhile, the unresolved gap in PDF-based quantity takeoff represents the largest first-mover opportunity in the open-source AEC ecosystem, and two major incumbents (Autodesk and Bentley) have begun open-sourcing their automation layers—strong evidence that the proprietary oligopoly recognizes the competitive threat and is adapting. Firms that build on free, interoperable tooling in the next 12 months will establish cost structures competitors cannot match.

3. Open Source Spotlight

Project A: ThatOpen Engine v3.4.8

What It Is: A component library for building browser-native BIM applications; includes 3D viewing, markup, selection, and measurement capabilities.

Problem It Solves: Eliminates the need for Bluebeam seats and desktop BIM viewers for submittal review workflows. Field teams can access interactive 3D models from any browser, annotate issues, and share feedback without software installation or version conflicts.

Setup Complexity: LOW - Available via npm (npm install @thatopen/components) - Comprehensive documentation at thatopen.com - Example applications deployable in under an hour - No server infrastructure required for basic viewing

Maturity Assessment: PRODUCTION-READY - Version 3.4.8 indicates stable release cadence - 149,000+ weekly npm downloads for web-ifc (the underlying engine) confirms community adoption - Active development with regular releases - Suitable for immediate pilot on non-critical submittal review workflows

GitHub: https://github.com/ThatOpen/engine

Project B: OpenDroneMap + CloudCompare Stack

What It Is: Open-source photogrammetry pipeline (ODM) paired with point cloud processing (CloudCompare) for survey-grade as-built verification at zero licensing cost.

Problem It Solves: Replaces $10,000–$50,000 annual photogrammetry software budgets with free, in-house capability. Enables pre-installation anchor verification and post-installation tolerance checks on every project.

Setup Complexity: MEDIUM - OpenDroneMap runs on local hardware or cloud instances (Docker container available) - CloudCompare is a desktop application with straightforward installation - Basic photogrammetry processing requires consumer-grade drone and 20–30 overlapping photos per area of interest - Initial setup and calibration requires 1–2 days of familiarization

Maturity Assessment: PRODUCTION-READY - Established project with 15,000+ GitHub stars (ODM) - Used by surveying professionals and construction firms globally - Point cloud comparison features are stable and validated - CloudCompare is a mature, decade-old tool with active maintenance

GitHub: https://github.com/OpenDroneMap/ODM | https://github.com/CloudCompare/CloudCompare

Project C: web-ifc v0.0.77

What It Is: The foundational IFC parsing library for JavaScript environments; enables native-speed reading and writing of IFC files in browsers, Node.js, or any JavaScript runtime.

Problem It Solves: Transforms IFC from a collaboration file format into a programmable data source. PGC can extract glazing quantities, door and window counts, and panel dimensions directly from BIM models without AutoCAD or Revit dependencies.

Setup Complexity: LOW - Single npm package: npm install web-ifc - Comprehensive API documentation - Example code available for common operations (extracting walls, windows, quantities) - No build tooling required for basic integration

Maturity Assessment: PRODUCTION-READY - 149,879 weekly npm downloads (approximately 7.8 million annually) - Active maintenance with 77 releases - Both independent analyses confirm production readiness - Cornerstone of the open BIM ecosystem

GitHub: https://github.com/tomvandig/web-ifc

4. Try It This Week

These tools require minimal setup and deliver immediate value for PGC workflows:

For BIM Review and Submittal Markup

ThatOpen Engine — Interactive BIM Viewer Demo - Action: Open the live demo at https://thatopen.com/demo in Chrome or Edge - What You'll See: A browser-based 3D model with markup, measurement, and selection tools - Next Step: Upload a sample glazing shop drawing (in IFC or glTF format) to test annotation workflows - Time Required: 15–30 minutes - Why This Week: Confirms whether browser-based review can replace Bluebeam for your submittal process

For As-Built Verification

OpenDroneMap — Cloud Processing Trial - Action: Deploy the free WebODM cloud instance or install Docker locally, then process a set of 30–50 overlapping drone photos from a current project site - What You'll Get: Orthomosaic, digital elevation model, and point cloud of the site - Time Required: 2–3 hours for first processing run (subsequent runs faster) - Why This Week: Establishes baseline familiarity before the next site visit where verification is needed

For Quantity Extraction

web-ifc — Basic IFC Query Test - Action: Run the following in a browser console or Node.js environment:

import { WebIFC } from "web-ifc";
const ifc = new WebIFC();
const model = await ifc.OpenModel("your-file.ifc");
const walls = ifc.GetLineIDsWithType(model, 173); // Wall type
console.log("Wall count:", walls.size());
  • What You'll Get: Wall count from any IFC file without Revit or Navisworks
  • Time Required: 30 minutes (including installing Node.js if needed)
  • Why This Week: Validates the foundation for building custom glazing quantity takeoff tools

For Point Cloud Comparison

CloudCompare — Tolerance Verification - Action: Download CloudCompare at https://www.cloudcompare.org, then open a sample point cloud alongside a DXF or IFC of the same space - What You'll Get: Visual comparison showing deviations between captured as-built conditions and design model - Time Required: 1 hour - Why This Week: Determines if CloudCompare meets tolerance verification needs before committing to full OpenDroneMap pipeline

Strategic Implications for PGC

The open-source AEC ecosystem has crossed a threshold: the core infrastructure for IFC parsing, BIM viewing, and photogrammetry is solved and freely available. The remaining competitive differentiation lies not in accessing these capabilities but in applying them faster and more creatively than competitors.

The PDF takeoff gap remains the largest unmet opportunity. No production-ready open-source tool automates quantity extraction from PDF submittals—the dominant format for architectural drawings in glazing workflows. Building this capability on web-ifc would establish a defensible advantage.

The action plan from this week's analysis:

  1. This quarter: Pilot ThatOpen Engine for submittal review; stand up OpenDroneMap for the next site verification project
  2. 6–12 months: Build PDF takeoff prototype on web-ifc; evaluate OpenConstructionERP takeoff module
  3. 12–18 months: Monitor pascalorg/editor and AI-assisted CAD developments; reassess based on maturity

The oligopoly is being bypassed, not attacked. Firms that build on free, browser-native, interoperable tools in the next 12 months will establish cost structures and workflow efficiencies competitors cannot match.
