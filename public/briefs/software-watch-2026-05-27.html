1. Fresco
Estimating

What it does: AI copilot for construction estimators — automates the entire takeoff process from plans. Processes site walk photos, videos, and voice notes into organized reports, punch lists, and logs. Claims 99% accuracy and 70% time reduction.

Legacy alternative: Manual takeoff (pen, scale ruler, spreadsheet) or first-gen digital takeoff tools (Bluebeam, PlanSwift)

Key differentiator: Targets Division 8 subs specifically — directly relevant to glazing contractors. Also handles site documentation (photos → reports) alongside takeoff. Integrates with Procore marketplace. YC-backed.

Pricing: Pre-seed / early access — not publicly listed

Glazing: High Try Now
📌 PGC MVP: Submit a sample set of glazing drawings to frescopm.com and compare 10 takeoff results against manual baseline. Estimated time: 2 hours.

2. OpenConstructionERP (v3.0)
Open Source ERP

What it does: Full open-source construction ERP — 71 modules covering BOQ, PDF/CAD/BIM takeoff, AI cost matching, procurement, project management. 42 regional cost catalogues, 21 languages. v3.0 released May 2026.

Legacy alternative: Sage, Procore, Viewpoint — proprietary ERP with $50k+ annual licensing

Key differentiator: AGPL-3.0 — completely free to self-host. AI-powered cost matching against regional catalogues. BIM-to-BOQ pipeline. pip install in one command.

Pricing: Free (AGPL-3.0), paid support/consulting available

Glazing: Medium Watch
📌 PGC angle: Self-hosting reduces data security concerns. Worth testing the AI takeoff module on a glazing spec PDF. Setup: pip install openconstructionerp

GitHub: datadrivenconstruction/OpenConstructionERP | openconstructionerp.com

3. PLAN0
Cost Intelligence

What it does: AI-powered construction cost intelligence platform. Analyzes architectural plans using computer vision to generate detailed cost estimates and analytics. Designed for real estate developers, investors, and GCs.

Legacy alternative: RSMeans manual lookup, Excel-based cost models

Key differentiator: CV-based plan analysis vs. template-based takeoff. YC-backed. Targets "weeks to 30 seconds" estimation.

Pricing: Not publicly listed

Glazing: Medium Watch
📌 PGC angle: If PLAN0 can read a full set of architectural drawings and auto-extract Division 08 scope, it could feed directly into PGC's budgeting process. Test by uploading a drawing set to plan0.ai.

YC W26 | plan0.ai

4. Articulate
Preconstruction

What it does: AI-powered drawing analysis for construction and solar contractors. Audits designs for code compliance before construction, detects clashes, auto-generates RFIs. Also accelerates takeoff and estimating.

Legacy alternative: Manual RFI generation, clash detection in Revit (requires full BIM)

Key differentiator: Works with PDF plans — no BIM required. Automatically generates structured RFIs from plan inconsistencies. YC F25 batch.

Pricing: Not publicly listed

Glazing: High Try Now
📌 PGC MVP: Upload a multi-page glazing spec PDF with elevation drawings. Let Articulate scan for code compliance issues and plan inconsistencies. Time: 1 hour.

7. Adam AI
AI CAD

What it does: Text-to-3D CAD tool for mechanical models, game assets, and prototypes. Generates parametric, editable parts from natural-language descriptions.

Legacy alternative: SolidWorks, Fusion 360 — manual 3D modeling from scratch

Key differentiator: From text prompt to parametric 3D model in seconds. Part editing and parametrization built in.

Pricing: From $9.99/month

Glazing: Low Watch
📌 PGC angle: Not directly applicable, but if PGC ever models custom frame profiles or mullion designs, this is the cheapest AI CAD option on the market.

8. SimplyWise Cost Estimator
Field Measurement

What it does: Mobile app combining LiDAR room scanning + AI-generated price estimate + ready-to-send quote PDF — all in one workflow. No training or special hardware required beyond an iPhone/iPad with LiDAR.

Legacy alternative: Tape measure + clipboard + separate estimating software

Key differentiator: End-to-end from scan to quote in one app. No CAD or BIM skills needed.

Pricing: Free tier available

Glazing: Medium Watch
📌 PGC MVP: Test the LiDAR scan on a framed opening. Does it capture accurate dimensions (width, height, depth)? Compare against tape measure. Time: 1 hour. Free.
