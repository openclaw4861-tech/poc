3. Open Source Spotlight

ThatOpen Engine v3.4.x

  • What it is: Browser-native engineering stack for AEC, including PDF markup, BIM viewing, and collaboration tools
  • GitHub: https://github.com/ThatOpen
  • Setup Complexity: Low. Browser-based deployment; no server infrastructure required for basic markup workflows
  • Maturity Assessment: Production-ready. Version 3.4.8 shipped multiple point releases within a single week, indicating active commercial sponsorship and rapid iteration driven by real user demand
  • Why PGC should care: Immediate Bluebeam replacement candidate. Cloud collaboration features eliminate version-control issues on submittals and shop drawings across field and office teams

web-ifc

  • What it is: High-performance IFC file parser and viewer for web applications
  • GitHub: https://github.com/IFCjs/web-ifc
  • Setup Complexity: Moderate. Requires JavaScript/TypeScript development environment; npm integration straightforward
  • Maturity Assessment: Ecosystem infrastructure. 200,000 weekly npm downloads; the research notes frame this accurately—"when a parsing library crosses 200K weekly downloads, it stops being a choice and becomes a dependency of the ecosystem itself"
  • Why PGC should care: Foundation for custom quantity extraction dashboards. Enables PGC to pull glazing quantities directly from BIM models received from architects and GC, eliminating manual takeoff labor

FreeCAD

  • What it is: Open-source parametric 3D CAD application with strong BIM and fabrication modeling capabilities
  • GitHub: https://github.com/FreeCAD/FreeCAD
  • Setup Complexity: Moderate. Desktop application; learning curve for teams accustomed to AutoCAD or Revit workflows
  • Maturity Assessment: Production-ready for targeted use cases. 33,373 GitHub stars with consistent weekly growth; design-to-fabrication path confirmed shipping, not theoretical
  • Why PGC should care: Pilot candidate for non-complex curtain wall assemblies and fabrication modeling. Reduces CAD licensing costs on back-office and detailing workflows
