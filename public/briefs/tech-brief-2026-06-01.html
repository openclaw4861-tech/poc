🔗 How the Trends Connect

The through-line of this week's research: AI agents are becoming infrastructure.

  • Skills (Matt Pocock, Taste-Skill) = the package manager for AI capabilities
  • Agent protocols (MCP/A2A) = the TCP/IP layer connecting AI agents together
  • Memory systems = the database layer that makes agents useful long-term
  • Runtime security = the firewall layer for AI toolchains
  • Physical AI = the edge layer where AI meets the real world
  • Vertical AI = the application layer where domain expertise beats general intelligence

PGC's strategy: focus on the application layer (glazing expertise encoded in skills) and the protocol layer (MCP resources from PGC data), not competing in the infrastructure layer where Google, OpenAI, and Anthropic are spending billions.
