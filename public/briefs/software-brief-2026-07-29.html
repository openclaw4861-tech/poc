1. Executive Summary

The open-source AEC software stack has crossed a critical inflection point this week, with browser-based BIM viewing, drone photogrammetry, and point cloud processing now all production-ready at near-zero software cost. The strongest development: ThatOpen Engine (@thatopen/components v3.4.8) has achieved the consensus of both independent analyses as ready for immediate deployment, directly replacing legacy PDF-based submittal workflows. A strategic void remains in PDF-based quantity takeoff—this represents the largest unresolved gap and a genuine first-mover opportunity for Pacific Glazing. Implementation speed now determines competitive advantage in the transition from 20-year-old legacy tools.

3. Open Source Spotlight

A. ThatOpen Engine — Browser-Based BIM

Maturity: ⭐⭐⭐⭐⭐ Production-Ready Setup Complexity: Low (npm package, documentation comprehensive) License: Apache 2.0

This is the strongest consensus finding across both analyses. The web-ifc core (v0.0.77, 96,352 weekly npm downloads) has crossed into production maturity. It renders IFC files directly in any modern browser without desktop software, plugins, or licensing fees. For PGC, this means submittal workflows currently dependent on Bluebeam or Adobe Acrobat can migrate to interactive 3D models clients can review without specialized software. The team can embed viewers in internal portals or send lightweight links instead of multi-gigabyte files.

Immediate Use Case: Replace PDF-based submittal packages for curtain wall and storefront projects with hosted IFC viewers.

B. OpenDroneMap / WebODM — Drone Photogrammetry

Maturity: ⭐⭐⭐⭐ Production-Ready (with training) Setup Complexity: Medium (requires drone hardware, GPU recommended) License: GPL v3

OpenDroneMap generates survey-grade point clouds and orthomosaics from consumer drone imagery. Commercial drone surveys cost $3,000–$15,000 per engagement; the software cost is near zero. WebODM provides the web interface for processing, making it accessible to staff without Linux command-line expertise. For PGC, this enables rapid as-built facade documentation, pre-bid site capture, and change-order verification without external survey contracts.

Immediate Use Case: Pilot drone + WebODM workflow on a single facade project to compare output quality against traditional survey.

C. Speckle — AEC Data Interoperability

Maturity: ⭐⭐⭐⭐ Established, Growing Setup Complexity: Medium (server component + connectors) License: Apache 2.0

Speckle connects Revit, Rhino, Grasshopper, and other design tools into a centralized data stream. It is an open-source alternative to Autodesk Forge for firms wanting to build glazing-specific geometry pipelines without per-API-call costs. For PGC, Speckle could standardize how glazing geometry flows from architectural models into fabrication drawings, eliminating manual translation steps that introduce errors.

Immediate Use Case: Evaluate Speckle connectors for any existing Rhino/Grasshopper workflows; monitor as alternative to Forge for in-house development.
