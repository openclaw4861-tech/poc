1. Executive Summary

The biggest signal this week: enterprises are moving AI infrastructure in-house. Odysseus (58k GitHub stars) and similar self-hosted AI workspace tools show strong demand for privacy-preserving, vendor-independent AI—directly relevant to PGC if handling sensitive project specs or client data. Agent memory systems are maturing fast; persistent context layers using vector databases (Qdrant) are becoming standard for enterprise AI assistants. Vision-language models for robotics are advancing toward real-world deployment, which could eventually impact installation labor markets. For PGC, the immediate opportunity is using these open-source building blocks to build internal AI tools—spec assistants, quality checks, training chatbots—at a fraction of SaaS costs.

2. Top 5 Technology Trends

🔴 Trend 1: Self-Hosted AI Infrastructure

What it is: AI systems that run entirely on your own hardware/cloud, eliminating dependence on OpenAI, Anthropic, or other third-party APIs.

Why it matters: - Full data control—critical for project specs, client quotes, and proprietary installation methods - Cost predictable; no per-token pricing that scales with usage - Customizable for glazing-specific terminology and workflows

Example: Odysseus (58k ⭐) is the leading self-hosted AI workspace. You deploy it, you own it, you control the data.

PGC Relevance: Build a private AI assistant trained on your glass catalogs, building codes, and installation procedures—no data leaves your infrastructure.

🟡 Trend 2: Agent Memory & Persistent Context

What it is: AI systems that remember previous interactions, project history, and accumulated knowledge across sessions—rather than treating every query as a blank slate.

Why it matters: - Enables AI assistants that "know" your company—previous projects, client preferences, common issues - Structured fact storage means consistent answers across teams - Vector databases (like Qdrant) make semantic search fast and accurate

Example: Memory-OS (936 ⭐) adds persistent memory to LLM agents using Qdrant. Munder-difflin (395 ⭐) coordinates multiple local AI agents.

PGC Relevance: A glazing spec assistant that remembers "last project was a hospital with strict fire ratings" and applies that context automatically.

🟡 Trend 3: Vision-Language-Action (VLA) Models for Robotics

What it is: AI systems that process visual input (cameras), understand language commands, and output physical actions—enabling robots to follow instructions based on what they see.

Why it matters: - TempoVLA: Speed-controllable robot manipulation (move faster or slower based on context) - HANDOFF: Whole-body humanoid control from AI "teachers" - These aren't lab experiments anymore—moving toward real deployment

PGC Relevance: Long-term threat/opportunity. Robotic glass installation is years away, but monitor this space. The glazing labor market could be disrupted.

🟢 Trend 4: Edge AI & Computer Vision

What it is: Running AI models on local hardware (not cloud)—enabling real-time visual inspection, defect detection, or quality control without internet dependency.

Why it matters: - ESP32-Plane-Radar (401 ⭐): AI on $5 hardware chips - Industrial cameras + edge AI = instant quality checks on the production floor - No latency, no cloud costs, no privacy leaks

PGC Relevance: Defect detection on glass surfaces. An edge device could flag scratches, bubbles, or coating issues in real-time during installation or fabrication.

🟢 Trend 5: 2D-to-3D Conversion (3D Gaussians)

What it is: AI that takes a single 2D image and generates a full 3D model you can rotate, zoom, and manipulate.

Why it matters: - TripoSplat converts images to variable 3D Gaussians—fast, high-quality - Potential to generate 3D building visualizations from site photos - Could enhance client proposals with quick 3D mockups

PGC Relevance: Generate 3D glass facade mockups from architect drawings or site photos. Useful for client presentations and design validation.

3. Trend Overlaps

4. MVP Experiments (1-7 Days, Low Cost)

⚡ Experiment 1: AI Glass Specification Assistant

Time: 3 days
Cost: ~$50 (API calls) or $0 (self-hosted)
Goal: Answer "What glass do I need for [project type]?"

Steps: 1. Compile 20-30 sample spec documents (your existing docs) 2. Use Ollama (free, self-hosted LLM) + Qdrant (free vector DB) 3. Ingest documents, create searchable knowledge base 4. Deploy simple chat interface

Success Metric: Can answer glazing questions with context from your docs.

⚡ Experiment 2: Vision Defect Detection Demo

Time: 2 days
Cost: ~$25 (cloud compute) or $0 (local)
Goal: Prove AI can distinguish good glass from defective glass.

Steps: 1. Collect 50 images: 25 defective (scratches, bubbles), 25 acceptable 2. Use LLaVA or GPT-4V API for zero-shot classification 3. Feed images, ask "Is this glass defective? What's the issue?"

Success Metric: Correctly identifies defects >80% of the time.

Note: This is a demo to show leadership what's possible. Full production would require more data and edge deployment.

⚡ Experiment 3: Thermal Performance Chatbot

Time: 1 day
Cost: ~$10 (API calls)
Goal: Answer "What's the U-factor for [glass type] in [climate zone]?"

Steps: 1. Create structured data from your product specs (U-factor, SHGC, visible transmittance) 2. Build prompt templates that query this data 3. Connect to a simple web chat widget

Success Metric: Accurate answers to 10 common thermal performance questions.
