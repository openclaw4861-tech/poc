1. Executive Summary

This week's analysis confirms that browser-based BIM viewing has reached production maturity, with ThatOpen's ecosystem decisively displacing legacy alternatives for glazing submittal workflows. Open-source photogrammetry tools have achieved cost parity with commercial survey options, presenting an immediate opportunity to reduce facade documentation expenses. Most significantly, the PDF-based quantity takeoff space remains the largest untapped opportunity—no production-ready open-source solution exists—creating a potential 12-month first-mover window for companies willing to invest in custom development. For Pacific Glazing, immediate action is warranted on browser BIM deployment, with medium-term strategic planning required around the takeoff gap and parametric glazing libraries.

3. Open Source Spotlight

Spotlight 1: ThatOpen Engine + web-ifc

What It Does: Enables viewing, editing, and managing IFC BIM files entirely in a web browser without AutoCAD, Revit, or Bluebeam dependencies.

Maturity: Production-ready; 99,423 weekly npm downloads and growing. Procore's own SDK validates this as the industry direction.

Setup Complexity: Low. JavaScript/TypeScript developers can integrate within days. Pre-built components available for common workflows.

Relevance to PGC: Replace current Bluebeam dependency for submittal workflows. Embed IFC viewers in project portals, automate submittal generation, and reduce per-seat licensing costs.

Resource: https://github.com/ThatOpen/engine

Spotlight 2: OpenDroneMap

What It Does: Transform drone-captured photos into georeferenced 3D point clouds, digital surface models, and orthomosaics—competent replacements for traditional topographic and facade surveys.

Maturity: Production-ready; widely adopted in surveying and construction monitoring. Version 3.x significantly improved accuracy and processing speed.

Setup Complexity: Medium. Self-hosted option requires Linux server or Docker container. Cloud hosting options reduce technical barrier. Commercial services (WebODM) offer managed deployment.

Relevance to PGC: Document existing facade conditions for retrofit bidding, verify field measurements against design, generate as-built records for complex curtain wall projects.

Resource: https://github.com/OpenDroneMap/ODM

Spotlight 3: CadQuery

What It Does: Python-based parametric 3D CAD kernel for building and manipulating geometry. Unlike traditional CAD, CadQuery scripts define geometry procedurally, enabling automated component generation.

Maturity: Active development (v2.x); stable API. Used in manufacturing and engineering but limited AEC adoption.

Setup Complexity: Medium. Requires Python knowledge. Documentation improving. Works well with FreeCAD for visualization.

Relevance to PGC: Potential to build custom libraries for standard glazing components—mullion sections, hardware templates, panel configurations—that can be regenerated programmatically for project-specific requirements.

Resource: https://github.com/CadQuery/cadquery

4. Try It This Week

These tools require minimal setup and can provide immediate value:

For BIM Viewing (Zero Commitment)

ThatOpen BIM Viewer (Web-based) https://thatopen.github.io/engine-viewer/

  • Open any sample IFC file directly in browser
  • No installation required
  • Test: Navigate a glazing-heavy model, zoom to curtain wall intersections, inspect panel dimensions
  • Time required: 15 minutes

For Photogrammetry Exploration

OpenDroneMap WebODM (Cloud-hosted demo) https://www.opendronemap.org/webodm/

  • Upload a few test photos of a building facade
  • See point cloud and orthomosaic output
  • No local installation required for evaluation
  • Time required: 30 minutes + processing time

For Takeoff Workflows

PDF iRoe / Measure PDF Areas (Browser-based) https://pdf.area-calculator.app/ (example tool; verify current options)

  • Upload a facade elevation PDF
  • Measure panel areas, window openings, and facade zones
  • Compare against manual Bluebeam workflows
  • Time required: 20 minutes

For Parametric Component Thinking

OpenSCAD (Desktop Download) https://openscad.org/downloads.html

  • Download and install (Windows/Mac/Linux)
  • Work through built-in tutorials to understand script-based modeling
  • Useful exercise: Model a simple mullion cross-section
  • Time required: 1-2 hours
