1. Executive Summary

This week's research confirms that the open-source AEC stack has reached production maturity for core glazing workflows—browser-native BIM viewing, 2D drafting, and AI-driven quantity extraction are no longer aspirational but available immediately at zero licensing cost. The most significant development: the pascalorg/editor project demonstrates AI agents can now read and write BIM data directly via the MCP protocol, bypassing proprietary APIs entirely. For PGC, two of three remaining proprietary beachheads (shop drawings and BIM viewing) can be replaced this quarter. The last gap—open-source PDF takeoff extraction—remains unaddressed, but the clock is running on that market.

3. Open Source Spotlight

A. ThatOpen Engine + web-ifc Stack

Setup Complexity: Low (WASM-based, runs in any modern browser) Maturity: Production-mature; used as infrastructure by commercial platforms

This combination provides browser-native BIM viewing without any desktop installation. The curtain wall documentation workflow—including markup and specification extraction—is fully functional. For PGC, this means project managers and field crews can review glazing models on any device without Navisworks licenses. The stack loads IFC files directly; no conversion or cloud upload required.

Try it: Clone the ThatOpen Engine examples, load a sample IFC file, and navigate a curtain wall model in under 30 minutes.

B. LibreCAD

Setup Complexity: Low (Windows/Mac/Linux installers; portable version available) Maturity: Stable; active community since 2011

LibreCAD is a 2D drafting tool that reads and writes DXF and DWG files. For PGC, this directly replaces AutoCAD for shop drawing production. The interface is older than modern tools, but the file compatibility is complete. Fabricators can continue using existing drawing templates without file conversion.

Try it: Open a current shop drawing in LibreCAD, make a simple revision, and save back to DXF.

C. CloudCompare

Setup Complexity: Medium (desktop application with some configuration for point cloud workflows) Maturity: Production-ready; used widely in surveying and fabrication QA

CloudCompare compares point clouds (from laser scans) against BIM models to identify dimensional deltas. For PGC, this is a direct margin lever: verifying unitized fabrication against field conditions before installation reduces costly remakes. The workflow fits into pre-fabrication release checks.

Try it: Import a point cloud scan and an IFC model, run the default distance comparison, and review the delta report.

4. Try It This Week

The following tools require minimal setup and provide immediate value to PGC workflows:

  1. ThatOpen Engine (Browser BIM Viewer)

    • What: View curtain wall IFC models in any browser, add markup and annotations
    • Who benefits: Project managers, field supervisors
    • Time to value: 30 minutes
    • URL: thatopen.com

  2. LibreCAD (2D Shop Drawings)

    • What: Open and edit DXF/DWG shop drawings without AutoCAD
    • Who benefits: Detailers, fabrication leads
    • Time to value: 1 hour
    • URL: librecad.org

  3. pascalorg/editor (AI Quantity Extraction)

    • What: Extract quantities from IFC models using AI agents via MCP protocol
    • Who benefits: Estimators, preconstruction team
    • Time to value: 2 hours (including MCP setup)
    • URL: github.com/pascalorg/editor

  4. web-ifc Demo (IFC Parsing)

    • What: Confirm browser can load and parse IFC files without plugins
    • Who benefits: IT/operations, anyone evaluating browser-native BIM
    • Time to value: 15 minutes
    • URL: github.com/tomvandig/web-ifc
