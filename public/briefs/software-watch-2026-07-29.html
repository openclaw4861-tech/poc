ODA MCP Servers

CAD/BIM / Developer Tools

What it does: The Open Design Alliance (ODA) is exposing its CAD-format SDKs to AI agents through self-hosted MCP servers. AI agents can read, write, and manipulate native DWG, DGN, and IFC files directly — opening up CAD/BIM data to the AI agent ecosystem at scale.

Legacy alt: Manual CAD data extraction, custom scripting with ODA SDKs, proprietary API integrations

Differentiator: First time ODA's industry-standard CAD/BIM SDKs are exposed via MCP for AI agents. Self-hosted (data stays private). Enables AI agents to work directly with native CAD files.

Pricing: Free for ODA members (membership required for SDK access; MCP servers are self-hosted)

Glazing: Medium

MVP: If PGC has ODA membership, spin up the MCP server and connect an AI agent to read a curtain wall DWG. Test: can the agent extract glass panel counts, frame lengths, and anchor points?

Stabileo

CAD/BIM / Structural Engineering

What it does: Open-source 2D & 3D structural analysis running entirely in the browser using the Direct Stiffness Method. No installation, no license server, no Windows requirement. Real-time solving with a visual interface. MIT licensed.

Legacy alt: SAP2000 ($2,000+/yr), ETABS ($2,500+/yr), Robot Structural Analysis ($3,000+/yr), RFEM ($3,500+/yr) — all Windows-only, expensive, closed-source

Differentiator: Browser-native, free, open-source. No installation at all — open stabileo.com and start. Direct Stiffness Method with real-time solving.

Pricing: Free (MIT open-source)

Glazing: Low

MVP: Model a simple curtain wall mullion span. Apply wind load and check deflection. Compare results against your current structural analysis tool.
