Bidflow

AI / Estimating (CAD Takeoff)

What it does: AI platform that scans complex CAD drawings and extracts quantities using vision models. Built to replace manual symbol-counting on electrical drawings — hours of work done at 99% accuracy in minutes. YC Summer 2026 batch.

Legacy alt: Manual CAD symbol counting + human error + spreadsheets

Differentiator: Vision-model approach to reading CAD symbols is directly applicable to any trade. If it can count electrical symbols at 99% accuracy, it can count glazing panel marks, hardware sets, and opening designations the same way.

Pricing: Not publicly listed — beta access available

Glazing: High

MVP: Upload a set of glazing shop drawings (PDF or DWG) and see if Bidflow correctly identifies panel designations, opening numbers, and hardware tags.

Civils.ai

Estimating / Takeoff (Glazing & Facade)

What it does: Purpose-built AI platform for glazing and facade estimation. Extracts vision vs. spandrel areas, breaks down by cladding type, splits by elevation and floor zone from elevation PDFs. Draft outputs reference exact source sheets for fast QA. Human review built into the workflow.

Legacy alt: Manual elevation tracing + highlighters + spreadsheets + Bluebeam

Differentiator: The only AI tool this cycle explicitly designed for glazing and facade work — not generic construction takeoff repurposed. Elevation-by-elevation and floor-zone breakdowns match how glazing contractors actually price bids.

Pricing: Pay-per-takeoff (per-sheet pricing on官网); free trial available

Glazing: High

MVP: Upload 3-5 elevation PDFs from a recent project. Run the glazing-by-elevation prompt and compare draft output time vs. manual tracing.

Opusense AI

Field Documentation / Voice Reports

What it does: AI assistant that generates structured field inspection reports from voice notes and photos in real time. Inspectors walk a site, speak observations aloud, snap photos, and receive a detailed organized report on-site — no more end-of-day typing. YC-backed.

Legacy alt: Manual field notes + end-of-day typing + photo filing + Word docs

Differentiator: Real-time — report is generated while the inspector is still on site. Directly addresses the 20%-of-week documentation burden that field teams accept as normal.

Pricing: Not publicly listed — demo available

Glazing: High

MVP: Have a site inspector use Opusense for one week on a glazing project. Compare documentation time vs. previous manual method.

Helonic

CAD/BIM / Preconstruction (Drawing Review)

What it does: AI platform that analyzes PDF plans, detects clashes and inconsistencies across disciplines (architectural, structural, MEP), and generates draft RFIs automatically. Integrates with Procore and Autodesk. YC F2025 batch.

Legacy alt: Manual clash detection + Navisworks coordination meetings + handwritten RFIs

Differentiator: Catches design clashes before construction starts — cost avoidance, not just productivity. Auto-generated draft RFIs save hours of manual documentation per project.

Pricing: Not publicly listed — contact for demo

Glazing: High

MVP: Upload a set of curtain wall shop drawings alongside architectural and structural PDFs. Review what clashes Helonic finds vs. what you caught manually during coordination.

Try Now

OpenConstructionERP v3.5

ERP / Full-Stack (Open Source)

What it does: Free, open-source ERP platform for construction companies. Covers estimating, project management, inventory, field tracking, accounting, and HR. Self-hosted (your own server or cloud). v3.5 adds improved AI features, better API integrations, and mobile UI refinements.

Legacy alt: QuickBooks + spreadsheets + pen-and-paper inventory + disconnected PM tools

Differentiator: Genuinely free and self-hosted — no per-seat licensing, no vendor lock-in, no subscription. Full-stack from estimating to accounting with active open-source community.

Pricing: Free (self-hosted); optional paid community support

Glazing: High

MVP: Spin up the free self-hosted instance. Import one active project's data (estimations, PO receipts, time entries). Evaluate against your current QuickBooks + spreadsheet workflow.
