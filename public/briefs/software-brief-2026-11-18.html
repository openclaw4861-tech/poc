WEEKLY CONSTRUCTION SOFTWARE BRIEFING

To: Steve Watts, CEO, Pacific Glazing Corporation
Date: November 18, 2026
Re: Open-Source AEC Stack Hits Production for Glazing, Facades, and Project Management

Executive Summary

This week, the open-source AEC stack crossed firmly into production territory for glazing contractors, with the web-ifc kernel and ThatOpen v3.6.x release train forming a complete, browser-native alternative to Autodesk authoring tools. Agent-native CAD tools shipping MCP servers now allow AI agents to query and edit geometry directly, while OpenProject validated its BCF-native workflows as a credible, self-hosted replacement for Procore and ACC issue tracking. On the reality-capture front, the combination of ODM, Point Cloud Library, and Draco is ready for facade as-built verification, though strong open-source alternatives for PDF takeoff and 2D drawing comparison remain unfilled. Pacific Glazing Corporation should move immediately to pilot OpenProject on a live project and benchmark the two leading browser IFC viewers before proprietary AI platforms replicate these open interfaces behind closed APIs.

Top 10 Software Developments

Rank Tool / Project GitHub URL What It Solves for PGC
1 ThatOpen Engine v3.6.x (@thatopen/components, bim-fragment, components-front) https://github.com/ThatOpen/engine_components A complete zero-Autodesk BIM authoring SDK. PGC can view, fragment, and manipulate facade IFC models in a browser without Revit or Navisworks licenses, and the bim-fragment format is optimized for fast loading of large curtain-wall datasets on field tablets.
2 web-ifc v0.0.79 https://github.com/ThatOpen/web-ifc The underlying browser-native IFC kernel logging over 529,000 weekly downloads. It parses IFC 4.x geometry and properties for IfcCurtainWall and IfcWindow elements client-side, making it the core engine for any custom takeoff or verification tool PGC builds.
3 OpenProject (BCF-native) https://github.com/opf/openproject A self-hosted, open-source replacement for Procore and ACC. Its native Building Collaborative Format (BCF) support preserves 3D viewpoint and camera-position data during punch-list and RFI workflows, which is critical for glazing issue resolution.
4 pascalorg/editor https://github.com/pascalorg/editor An agent-native CAD environment that ships an MCP server, enabling AI agents to query and edit geometry directly. For PGC, this opens the door to automated quantity extraction from IfcCurtainWall assemblies without traditional manual takeoff software.
5 @xeokit/xeokit-bim-viewer v2.7.1 https://github.com/xeokit/xeokit-bim-viewer A performance-oriented browser viewer built specifically for massive models. PGC should benchmark this against ThatOpen on its largest facade IFC to determine which loads faster and uses less memory on site tablets.
6 OpenDroneMap (ODM) https://github.com/OpenDroneMap/ODM An open-source photogrammetry pipeline that turns drone imagery into georeferenced point clouds and meshes. PGC can use it to document completed facade installations and verify them against design intent without proprietary reality-capture subscriptions.
7 Point Cloud Library (PCL) https://github.com/PointCloudLibrary/pcl The industry-standard open library for 2D/3D point cloud processing. PGC can run deviation analysis between drone-captured facade point clouds and the original design IFC to catch installation variances before final sign-off.
8 SolidCraft https://github.com/SolidCraft/SolidCraft An MCP-enabled CAD environment for script-driven part generation. PGC can automate bracket, plate, and anchor drawings with parametric inputs, exporting STEP or DXF directly to fabrication equipment.
9 Draco https://github.com/google/draco A geometry compression library that dramatically reduces point-cloud and mesh file sizes. For PGC, this means faster transfer of as-built facade scans from the field to the office over standard mobile networks.
10 @bentley/construction-schema v1.0.4 https://www.npmjs.com/package/@bentley/construction-schema Bentley quietly open-published this schema on npm, signaling that interoperability pressure is forcing proprietary vendors to concede open data formats. PGC should monitor this to ensure future subcontractor model exchanges do not rely solely on closed Bentley formats.

Open Source Spotlight

1. OpenProject
GitHub: https://github.com/opf/openproject
Maturity: Enterprise-grade. 17.4k stars and a long release history; the BCF plugin is stable enough for production issue tracking.
Setup Complexity: Low to Moderate. A Docker-based install can be running in under an hour, but PGC will need to verify that BCF viewpoint and camera metadata round-trip correctly between OpenProject and existing model viewers before declaring it a Procore replacement.

2. ThatOpen Components + web-ifc
GitHub: https://github.com/ThatOpen/engine_components and https://github.com/ThatOpen/web-ifc
Maturity: Production. The kernel logs over 529,000 weekly downloads and the v3.6.x SDK is a complete, zero-Autodesk authoring environment.
Setup Complexity: Moderate to High. These are browser-native libraries, not desktop executables. PGC will need front-end development capacity or a systems integrator to embed them into internal tools, and must deliberately pin web-ifc to v0.0.79 due to volatile 0.0.x versioning.

3. @xeokit/xeokit-bim-viewer
GitHub: https://github.com/xeokit/xeokit-bim-viewer
Maturity: Stable and active. Version 2.7.1 resolves the confusion around the legacy package flatline; it is purpose-built for very large models.
Setup Complexity: Moderate. The scoped npm package migration means some older documentation still references deprecated names. It is best deployed by PGC's IT team into a controlled field-tablet dashboard for head-to-head load testing against ThatOpen.

Try It This Week

  • OpenProject BCF Pilot: Spin up OpenProject via Docker on a workstation, import the punch list from one active PGC project, and create a BCF issue linked to a 3D viewpoint in a facade IFC model. Verify that the camera position and selected component survive the round trip when reopened in a BCF-compatible viewer.
  • Browser IFC Smoke Test: Load the same project IFC into the ThatOpen viewer on a standard iPad or Android tablet. Isolate IfcCurtainWall elements and export a property CSV to confirm the data is accessible without Autodesk software.
  • Xeokit Load Benchmark: Load PGC's largest facade IFC into @xeokit/xeokit-bim-viewer v2.7.1 on the same tablet used for the ThatOpen test. Record initial load time, memory usage, and frame rate during orbit to establish a quantitative baseline for standardizing field hardware.

Ones to Watch

text-to-cad (26.7k stars) — https://github.com/zoo-dev/text-to-cad
An experimental generative-CAD tool that produces 3D hardware concepts from text prompts. Momentum is strong, but PGC should treat it as experimental until it outputs fabrication-grade STEP files verified by your CNC vendors. Ideal for rapid bracket prototyping once maturity arrives.

@bentley/construction-schema — https://www.npmjs.com/package/@bentley/construction-schema
Bentley's quiet move to open-publish its construction schema is an early signal that proprietary AEC data moats are weakening. If adoption spreads, PGC may soon receive open-schema models from project partners instead of locked DGN files. Monitor version releases for production stability.

Open-Source PDF Takeoff & Spec-Parsing Gap:
While no dominant open-source tool currently exists for PDF quantity takeoff or specification parsing, the agent-native CAD trend makes this the most likely remaining gap to close within the next 12 months. Watch for the first MCP-compatible PDF-to-quantity connector to emerge from the pascalorg/editor ecosystem or adjacent projects.
