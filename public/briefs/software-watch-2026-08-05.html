Text-to-CAD (earthtojake)

CAD/BIM / AI-Assisted Design
What it does: Open-source library of agent skills for CAD, CAE, and CAM. Describe 3D models in plain text and get CAD output. Integrates with existing CAD tools as an AI skill layer.
Legacy alternative: Manual 3D modeling in SolidWorks, Rhino, or Fusion 360
Key differentiator: Agent-based approach — skills are composable and can be chained. Not a replacement CAD tool but an AI layer on top of existing CAD workflows. MIT license.
Pricing: Free (open source, MIT)
Glazing applicability: Medium — Could accelerate parametric modeling of curtainwall panels, mullion profiles, and glass lite layouts.
MVP trial: Clone repo, run agent skills against a simple glazing profile
