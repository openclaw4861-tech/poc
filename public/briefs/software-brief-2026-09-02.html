1. Executive Summary

The open-source AEC software ecosystem has reached a decisive inflection point this week. web-ifc crossed 200,000 weekly downloads with 81–95% week-over-week growth, signaling that browser-native BIM processing has moved from experimental to mainstream infrastructure. ThatOpen Engine v3.4.x has achieved feature parity with Bluebeam Revu for markup workflows, presenting an immediate opportunity for PGC to eliminate $500 per-seat annual licensing costs. Meanwhile, the maturation of FreeCAD and xeokit confirms that a complete open-source BIM stack—from design to viewing—is now viable for production glazing workflows. The first-mover advantage window is closing rapidly as these tools cross critical adoption thresholds.

3. Open Source Spotlight

Spotlight 1: ThatOpen Engine v3.4.x

GitHub: https://github.com/ThatOpen/

Problem It Solves: Enables browser-based markup, annotation, and BIM component authoring without desktop software or per-seat licensing fees. Directly replaces Bluebeam Revu for internal workflows.

Maturity Assessment: Production-ready. Release cadence is sustained, npm adoption is growing, and feature parity with Bluebeam is confirmed by independent analysis.

Setup Complexity: Low. Available as npm packages (@thatopen/components, @thatopen/components-front). Requires basic JavaScript/TypeScript knowledge or a junior developer for integration. No server infrastructure required.

PGC Use Case: Pilot markup workflows on submittal documents and RFI responses within 30 days.

Spotlight 2: FreeCAD

GitHub: https://github.com/FreeCAD/FreeCAD

Problem It Solves: Parametric 3D modeling for custom hardware design—handrails, structural glass supports, and custom fittings—without $3,000+ annual CAD licensing costs.

Maturity Assessment: Production-viable for component design (no longer a hobbyist tool per independent analysis). 12–18 month timeline to full production use for complex BIM authoring; simpler component design could begin sooner.

Setup Complexity: Medium. Desktop application with steep learning curve for advanced features. OpenCASCADE kernel provides robust geometry capabilities. BIM workbench maturing rapidly.

PGC Use Case: Evaluate for custom hardware fabrication department. Prototype a single handrail bracket or glass clamp within 90 days to assess workflow fit.

Spotlight 3: web-ifc

GitHub: https://github.com/ifcjs/web-ifc

Problem It Solves: Client-side IFC file parsing in web browsers—enabling real-time quantity extraction, glazing takeoffs, and BIM data dashboards without server infrastructure or proprietary viewer licenses.

Maturity Assessment: Mainstream adoption confirmed. 200k weekly downloads represents a critical mass. Browser-native IFC is now the default approach for next-generation BIM tooling.

Setup Complexity: Low-to-Medium. npm package with comprehensive documentation. Requires JavaScript development capability for dashboard integration. Excellent for prototyping custom quantity extraction tools.

PGC Use Case: Prototype glazing quantity extraction dashboard. Load an IFC from a recent project, extract curtain wall panel counts, glazing square footage, and frame lengths automatically.
