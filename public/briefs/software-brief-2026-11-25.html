Pacific Glazing Corporation (PGC)

RE: Open-Source AEC Inflection and Q4 Priorities

1. EXECUTIVE SUMMARY

The open-source inflection in AEC software is now production-grade. ThatOpen Engine v3.6.x and web-ifc have reached 489,194 weekly npm downloads and can displace Autodesk Forge and Navisworks for browser-native IFC interrogation immediately. PGC should not renew legacy PDF takeoff licenses; instead, deploy model-based quantity takeoff this quarter using @thatopen/components, while piloting OpenProject as a self-hosted replacement for Procore/ACC field coordination. These are direct swaps requiring no kernel migration and immediately address glazing workflows from facade detailing to as-built verification.

2. TOP 10 SOFTWARE DEVELOPMENTS

1. ThatOpen Engine v3.6.x / web-ifc
- GitHub: https://github.com/ThatOpen/engine_web-ifc
- Relevance to PGC: Browser-native IFC parsing at 489,194 weekly npm downloads. Eliminates per-seat costs for Forge/Navisworks and lets PGC view federated facade models in any modern browser.

2. @thatopen/components
- GitHub: https://github.com/ThatOpen/engine_components
- Relevance to PGC: Native model-based quantity takeoff (QTO) embedded in the ThatOpen stack. PGC can extract glazing quantities, panel counts, and surface areas directly from IFC geometry this quarter, replacing PDF-based manual takeoff.

3. OpenProject
- GitHub: https://github.com/opf/openproject
- Relevance to PGC: Validated BCF-native issue tracking and self-hosted project management. Immediate replacement candidate for Procore/ACC on field coordination, RFIs, and punch lists without vendor lock-in.

4. bim-fragment v1.5.0
- GitHub: https://github.com/ThatOpen/fragment
- Relevance to PGC: Explicitly optimized for massive curtain-wall datasets, enabling sub-second browser loading of heavy facade models—previously gated behind desktop viewers. Critical for field tablet navigation.

5. FreeCAD
- GitHub: https://github.com/FreeCAD/FreeCAD
- Relevance to PGC: Stable parametric facade detailing with 35,763 GitHub stars. Shop teams can script extrusion profiles and export direct STEP files to fabrication equipment, bypassing intermediate CAD licenses.

6. OpenDroneMap (ODM)
- GitHub: https://github.com/OpenDroneMap/ODM
- Relevance to PGC: Open-source photogrammetry pipeline converting drone/site photography into georeferenced point clouds. Foundation for pre-installation facade verification on large glazing projects.

7. CloudCompare
- GitHub: https://github.com/CloudCompare/CloudCompare
- Relevance to PGC: Production-ready point cloud and mesh processing. PGC can run deviation analysis between as-built scans and design intent to catch curtain wall misalignment before glass is ordered or installed.

8. openMVS
- GitHub: https://github.com/cdcseacave/openMVS
- Relevance to PGC: Dense meshing for facade as-built verification. Fills the meshing gap alongside ODM, producing high-density surface models required for tight glazing tolerance checks.

9. OpenSCAD
- GitHub: https://github.com/openscad/openscad
- Relevance to PGC: Scripted shop geometry for immediate tactical wins. Fabrication teams can codify mullion and bracket geometry parametrically without heavy CAD overhead.

10. xeokit-sdk
- GitHub: https://github.com/xeokit/xeokit-sdk
- Relevance to PGC: Proven for embedded BIM portals, but carries a critical license-diligence warning. PGC must audit commercial licensing terms before embedding xeokit in any customer-facing client portal to avoid downstream liability.

3. OPEN SOURCE SPOTLIGHT

OpenProject
- Maturity: Production-ready. BCF-native issue tracking is validated and stable.
- Setup Complexity: Low-to-medium. A Docker Compose deployment or managed cloud instance can be running in under an hour; no kernel migration or retraining required.
- Assessment: Lowest-risk swap available. PGC should move one active project's RFI and field-issue workflow into OpenProject immediately to benchmark against Procore/ACC.

ThatOpen Engine (web-ifc + bim-fragment + components)
- Maturity: Production-grade. Browser-native IFC interrogation is no longer experimental; weekly npm adoption confirms industry trust.
- Setup Complexity: Low for evaluation (static HTML or npm install); medium for full QTO integration into existing estimating workflows.
- Assessment: The single highest-impact displacement opportunity. PGC can drop Navisworks/Forge this quarter and transition estimators to model-native QTO without changing the underlying IFC standard.

openMVS
- Maturity: Proven but narrow. 4,299 GitHub stars with a stable track record in dense reconstruction.
- Setup Complexity: Medium-to-high. Requires a Linux build environment, optional CUDA acceleration, and photogrammetry pipeline knowledge. Best paired with ODM outputs.
- Assessment: A tactical addition to the reality-capture stack. PGC should bundle this into the ODM/CloudCompare beta rather than deploying standalone.

4. TRY IT THIS WEEK

  • OpenProject Pilot: Deploy a self-hosted instance via Docker Compose. Import one project's current RFI log and run a week-long parallel test against Procore to validate BCF-native issue tracking for field crews.
  • ThatOpen Browser Viewer: Load a current PGC facade IFC model into the web-ifc browser viewer (CDN build available). Time the load and sectioning performance against your existing Navisworks workflow on a tablet.
  • Model-Based QTO Test: Use @thatopen/components to run quantity extraction on the same IFC. Export curtain wall panel counts and surface areas to CSV and compare accuracy against your last PDF takeoff.
  • FreeCAD Shop Test: Download the portable FreeCAD build. Model one parametric mullion extrusion and export a STEP file directly to your CNC or fabrication lead for tolerance review.
  • CloudCompare Deviation Check: If a recent site scan (LAS/E57) is available, import it into CloudCompare alongside the design mesh. Run a cloud-to-mesh distance check to quantify facade deviation before glazing installation begins.

5. ONES TO WATCH

  • pascalorg/editor: A scan-to-BIM and agent-intake tool served via an MCP server. It is newer but trending fast. PGC should scope a 30-day evaluation trial to test automated intake of field conditions into federated models, though it is not yet ready for production estimating.
  • solidcraft / text-to-cad: Rust-based geometry kernels and AI hardware generation pipelines. Monitor closely for future scripted component workflows in the shop, but do not commit production fabrication resources until the toolchain stabilizes.
