1. Executive Summary

The open-source AEC software ecosystem has reached an inflection point: browser-based BIM viewing infrastructure (web-ifc, xeokit, @thatopen/components) now offers production-quality alternatives to desktop-bound tools, enabling field-accessible model review without Revit licensing. FreeCAD's recent BIM module improvements make preliminary curtain wall design and quantity extraction viable without proprietary software. However, critical workflow gaps persist—particularly PDF-based takeoff automation—where the industry still lacks mature open-source alternatives to Bluebeam. Organizations evaluating the next-generation stack should prioritize browser-based BIM viewing as the lowest-friction entry point while monitoring the 18-24 month timeline for document automation solutions.

3. Open Source Spotlight

Spotlight 1: web-ifc + xeokit Stack

Purpose: Browser-based IFC viewing infrastructure that eliminates desktop software requirements for model review.

Setup Complexity: Low. web-ifc is available via npm (npm install web-ifc). xeokit provides pre-built examples. No compilation required for basic usage.

Maturity Assessment: High. 84K weekly npm downloads indicates production deployment at scale. Both projects have active maintainers and commercial backing.

Time to Value: 1-2 weeks for evaluation; 4-6 weeks for internal pilot.

Recommendation: Begin with xeokit's pre-built viewer to assess model loading performance, then evaluate web-ifc integration for custom workflow development.

Spotlight 2: FreeCAD

Purpose: Open-source parametric modeler positioned as the open alternative to Revit for modeling and quantity extraction.

Setup Complexity: Low-Medium. Available as Windows/macOS/Linux installer. Recent 1.0 releases have improved stability.

Maturity Assessment: Medium-High. 31K GitHub stars with active development. BIM workbench is functional but less polished than Revit; suitable for preliminary work and quantity takeoffs.

Time to Value: 2-4 weeks for basic proficiency; 8-12 weeks for production workflow integration.

Recommendation: Evaluate on a single pilot project for curtain wall concept modeling and glass quantity comparison against current Bluebeam-based methods.

Spotlight 3: OpenProject

Purpose: Full project lifecycle management platform with built-in IFC viewer and BCF issue tracking—directly challenges Procore and Aconex for contractor workflows.

Setup Complexity: Medium. Self-hosted option available or cloud subscription. Requires server administration for on-premise deployment.

Maturity Assessment: High. 15K stars with established user base; deployed in European infrastructure projects at scale.

Time to Value: 2-4 weeks for evaluation; 4-8 weeks for data migration from existing tools.

Recommendation: Compare against current Procore usage for scheduling, RFIs, and submittal tracking. Identify gaps before committing to migration.

Key Takeaways for PGC

  1. Browser-based BIM viewing is production-viable today. web-ifc/xeokit/thatopen stack should be evaluated before investing in additional desktop licenses.

  2. FreeCAD is ready for preliminary work. Quantity extraction and concept modeling can begin without proprietary software costs.

  3. PDF takeoff automation remains the critical gap. No open-source alternative to Bluebeam exists; monitor this space closely over the next 18-24 months.

  4. OpenProject warrants a direct comparison against current Procore usage for scheduling and issue tracking.

  5. CadQuery and OpenSCAD offer automation value for firms with Python scripting capability—higher learning curve but significant efficiency gains for repetitive configurations.
