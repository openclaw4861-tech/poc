Pacific Glazing Corporation | July 01, 2026 Prepared for: Steve Watts, CEO Week of: June 24, 2026

Executive Summary

The open-source AEC software stack has reached production viability this week, with web-ifc cementing its position as the dominant browser-based BIM viewer through record npm downloads (105,839 weekly). OpenDroneMap has achieved cost parity with commercial photogrammetry tools, enabling PGC to capture existing conditions for replacement glazing bids at zero software cost. A critical first-mover opportunity remains in PDF-based takeoff tooling, where no production-ready open-source alternative to Bluebeam Revu currently exists, creating a 12-month window for PGC to establish glazing-specific takeoff capabilities before the market catches up.

Top 10 Software Developments

1. web-ifc Viewer

Problem Solved: Browser-based IFC model viewing without Navisworks licensing costs Weekly npm Downloads: 105,839 GitHub: https://github.com/ifcjs/web-ifc Relevance to PGC: Eliminates $15,000–$30,000 per seat annual Navisworks licensing for model coordination and client presentations. Production adoption confirmed across multiple enterprise deployments. Status: Immediate deployment candidate for internal coordination portal.

2. OpenDroneMap (ODM)

Problem Solved: Reality capture and site documentation for facade surveys and existing conditions GitHub: https://github.com/OpenDroneMap/ODM Relevance to PGC: Zero-cost alternative to $5,000–$15,000 annual Agisoft or RealityCapture subscriptions. Now matches commercial output quality for point cloud generation. Status: Pilot recommended on next facade survey bid.

3. @thatopen/components

Problem Solved: Glazing panel count extraction, mullion length measurement, and sealant linear footage calculation from IFC models GitHub: https://github.com/ThatOpen/components Relevance to PGC: Directly applicable to quantity takeoff workflows for bid preparation. The QuantityExtractor component is production-ready. Status: Evaluate within 1–3 months.

4. ASSIMP (Open Asset Import Library)

Problem Solved: Interoperability between Rhino, Revit, AutoCAD, and web-based BIM viewers GitHub: https://github.com/assimp/assimp Relevance to PGC: Critical for building conversion pipelines when receiving CAD files from architects or fabricators in various formats. Enables consistent model ingestion regardless of source software. Status: Include in technical requirements for any custom development.

5. CloudCompare

Problem Solved: Point cloud processing, comparison, and analysis GitHub: https://github.com/CloudCompare/CloudCompare Relevance to PGC: Complements ODM for processing drone-captured site data. Enables comparison of as-built conditions against design models for replacement glazing assessments. Status: Integrate with ODM pipeline at 6–12 month horizon.

6. OpenProject

Problem Solved: Project management, scheduling, and team collaboration GitHub: https://github.com/opf/openproject Relevance to PGC: Open-source alternative to MS Project or Procore for internal project management. Zero licensing cost with self-hosting option. Status: 6-month trial recommended for internal PM replacement evaluation.

7. PDF.js

Problem Solved: Browser-based PDF rendering and manipulation GitHub: https://github.com/mozilla/pdf.js Relevance to PGC: Foundation for building custom PDF takeoff tools. Enables extraction of dimensions and quantities from drawing sets without Bluebeam licensing. Status: Use as development foundation for PDF takeoff prototype.

8. xeokit

Problem Solved: Enterprise-grade WebGL BIM visualization GitHub: https://github.com/xeokit/xeokit Relevance to PGC: Maintains enterprise relevance for existing integrations, though momentum has plateaued versus web-ifc's growth trajectory. Retain competency for legacy enterprise projects. Status: Maintain competency; do not prioritize for new projects.

9. FreeCAD

Problem Solved: Parametric 3D modeling and shop drawing creation GitHub: https://github.com/FreeCAD/FreeCAD Relevance to PGC: Potential zero-cost drafting tool for non-complex glazing element shop drawings. Python scripting enables customization for repetitive glazing details. Status: Evaluate for non-complex element drafting at 12+ month horizon.

10. earthtojake/text-to-cad

Problem Solved: Natural language to CAD geometry generation using AI agents GitHub: https://github.com/earthtojake/text-to-cad GitHub Stars: 7,350 Relevance to PGC: Signals investment direction toward generative facade design. Not production-ready but demonstrates emerging AI capabilities for glazing geometry creation. Status: Monitor for future development; not currently actionable.

Open Source Spotlight

1. web-ifc Viewer

Maturity: Production-ready (major version stable) Setup Complexity: Low Documentation: Comprehensive with live examples Assessment: Industry-standard browser-based BIM viewer with active development and largest AEC npm download volume. Immediate deployment is viable with standard web development resources. Community support is robust. Recommendation: Deploy within the month.

2. OpenDroneMap

Maturity: Production-ready (version 3.x stable) Setup Complexity: Low to Medium Documentation: Strong with Docker containerization available Assessment: Reaches commercial-grade output quality at zero cost. Standalone desktop application or cloud deployment options available. Processing time scales with site complexity. Recommendation: Pilot on upcoming facade survey bid.

3. @thatopen/components

Maturity: Production-ready (active development) Setup Complexity: Medium Documentation: Growing ecosystem with active community Assessment: Modular component library purpose-built for AEC applications. QuantityExtractor directly addresses glazing quantity takeoff needs. Requires JavaScript development competency. Recommendation: Evaluate within 1–3 months for panel count extraction workflow.
