Open Source Spotlight

1. ThatOpen Engine + web-ifc

Maturity: Production-Grade (v3.4.x release cadence, enterprise adoption evidence) Setup Complexity: Low (npm install, browser-based—no server infrastructure required) What It Replaces: Bluebeam Revu, Autodesk BIM 360 Viewer (for review-only workflows)

Why It Matters: This combination delivers feature parity with proprietary PDF markup and BIM viewing at zero licensing cost. Weekly npm downloads exceeding 143K (200K reported within one week) confirm this is production infrastructure, not experimental software.

PGC Workflow Fit: Shop drawing markup, dimensional verification, collaborative review with field crews, layer-based glazing element isolation.

2. OpenDroneMap (ODM) / WebODM

Maturity: Production-Ready (widely deployed in construction and surveying) Setup Complexity: Low-Medium (Desktop application for initial deployment; self-hosted server option for scale) What It Replaces: Third-party site survey services, manual measurement of existing conditions

Why It Matters: A mid-sized glazing company can implement site documentation workflows with existing hardware ($1,500 drone) and evaluate within a single project cycle. Orthomosaic and point cloud outputs directly feed into facade takeoff and existing conditions verification.

PGC Workflow Fit: Pre-bid site surveys, existing facade documentation, change order verification, punch list documentation.

3. FreeCAD

Maturity: Mature with Known Gaps (33,553 GitHub stars, active development) Setup Complexity: Medium (standard desktop installation; 2-3 week learning curve for parametric workflows) What It Replaces: AutoCAD (for component detailing), custom scripting for curtain wall documentation

Why It Matters: Only viable open-source parametric modeling option for glazing component detailing. Curtain wall complex geometry remains a gap, but standard component families (mullions, gaskets, hardware) are achievable with training.

PGC Workflow Fit: Fabrication drawings for custom glazing components, BOM extraction, IFC export for BIM coordination.

Try It This Week

Immediate Actions (No Setup Required / Browser-Based)

  1. ThatOpen Engine Demo — Open https://platform.thatopen.com and load a sample IFC model. Test dimension measurement and layer visibility toggling. No installation required.

  2. web-ifc on npm — For any team member with Node.js experience: npm install web-ifc and run the basic markup example at github.com/ThatOpen/web-ifc. Evaluate for next shop drawing review cycle.

  3. WebODM Cloud Trial — Sign up at webodm.net to process a test drone dataset without installing software. Upload imagery from a recent site visit to generate orthomosaic.

  4. xeokit Viewer Demo — Access xeokit.io and load the sample building model. Test navigation and measurement tools. Confirm active development status firsthand.

Low-Effort Desktop Tools

  1. LibreCAD — Download at librecad.org. Open a DXF file from a recent project. Assess readability of supplier drawings.

  2. FreeCAD (Basic) — Download at freecad.org. Complete the Part Design tutorial (2 hours) to assess familiarity with parametric workflow.
