12 New Tools for Glazing & Construction — May 6, 2026

Published: May 6, 2026 Type: Software Landscape Scan Prepared by: Joe 🔧 Next: May 13, 2026

This Week's Software Landscape

This week's scan found 12 new or recently launched tools spanning CAD, AI plan review, shop floor management, field intelligence, and construction PM. The biggest shift: AI-powered plan check is crossing from demo into production ($100/check vs $500-2,000 traditional), and cloud-native CAD is finally mature enough to replace desktop AutoCAD. Three tools stand out for PGC specifically: InspectMind ($100 code checks), Trunk Tools (AI spec review), and Fabriq (shop floor MES for glass fabrication).

Shapr3D
CAD (Mobile)
🟢 Try Now

What It Does

Full-featured 3D modeling CAD on iPad, Mac, and Windows with stylus/touch interface. Parametric modeling via SIEMENS Parasolid engine. Exports STEP, IGES, STL, DWG, DXF.

Legacy Alternative

AutoCAD / SolidWorks — desktop-bound, steep learning curve

Key Differentiator

Touch + stylus native on iPad. Cloud sync across devices. Real-time collaboration. Dramatically flatter learning curve. Perpetual-use local engine.

Pricing

Free tier (2 projects). Pro: ~$49/month ($239/year). Workspace: ~$89/month ($479/year).

Glazing Applicability

High — Field measurement sketching on iPad, client design iterations, export DXF for CNC cutting.

🧪 MVP Trial (30 min)

Download Shapr3D free. Model a simple curtain wall segment using built-in tutorials. Test parametric edits on a mullion profile.

Onshape
CAD (Cloud)
🟢 Try Now

What It Does

Full cloud-native CAD + PDM with Git-style version control (branching, merging, releases) and real-time multi-user collaboration in a browser.

Legacy Alternative

AutoCAD / SolidWorks / Inventor + separate PDM (Vault, Windchill)

Key Differentiator

Branch/merge workflow for parallel design exploration. No check-in/check-out. Runs in any browser — no GPU needed client-side. CAM and rendering add-ons. API for custom integrations.

Pricing

Free (public projects, 10 private docs). Standard: $1,500/user/year. Professional: $2,500/user/year.

Glazing Applicability

High — Branch/merge for curtain wall families. Shared mullion/aluminum extrusion libraries. CAM output for CNC.

🧪 MVP Trial (1 hour)

Create free Onshape account. Build a mullion profile as parametric part studio. Create a 4'×8' glazed panel assembly. Test branching for a different glass thickness.

Trunk Tools
AI Project Management
🟢 Try Now

What It Does

AI platform ingests all construction documents (specs, RFIs, submittals, schedules, contracts) and answers natural language questions, identifies risks, and auto-generates reports.

Legacy Alternative

Manual spec review + Procore document management

Key Differentiator

"Chat with your project." Upload hundreds of docs, ask natural language questions. AI identifies conflicting specs, flags missing submittals, highlights schedule risks. No manual re-keying.

Pricing

Custom enterprise pricing. Free demo available.

Glazing Applicability

High — Review glazing specs vs. architectural drawings for conflicts. Query all project docs for glass types, thermal performance, warranty obligations in seconds.

🧪 MVP Trial (2 hours)

Request demo at trunk.tools. Upload 3-4 specs for a glazing-heavy project. Ask: "What are all thermal performance requirements for vision glass?"

InspectMind
AI Plan Check
🟢 Try Now

What It Does

AI agent reviews construction drawings against IBC, IRC, IFC building codes, producing same-day plan check reports ready for permit submission.

Legacy Alternative

Manual plan check / third-party plan review services (days to weeks, $500-2,000+)

Key Differentiator

Same-day review from $100/check. Catches coordination errors across disciplines. YC W24 company. Dramatically cheaper and faster than traditional plan check firms.

Pricing

From $100 per plan check. Custom pricing for enterprise/portfolio accounts.

Glazing Applicability

High — Review glazing shop drawings for code compliance (wind load, impact resistance, thermal performance, egress). Catch curtain wall errors before fabrication.

🧪 MVP Trial (1 hour)

Visit inspectmind.com. Upload a glazing elevation drawing with structural notes. Request a code compliance check. Results in hours, not days.

Buildots
Progress Tracking
🟡 Watch

What It Does

Computer vision + AI tracks construction progress by analyzing 360° site photos against BIM models, providing real-time schedule compliance data.

Legacy Alternative

Manual superintendent walkthroughs + weekly progress photos

Key Differentiator

Site walk with 360° camera (Insta360, Theta). AI compares as-built photos against BIM/IFC models and project schedule. Flags deviations automatically. 50,000+ projects globally.

Pricing

Enterprise pricing (request quote). Per-project license.

Glazing Applicability

High — Track curtain wall installation progress vs. model. Auto-verify mullion placement, anchor locations, panel sequence from site photos.

🧪 MVP Trial (demo)

Request demo at buildots.com. Use on a project with unitized curtain wall to auto-track panel installation progress vs. schedule.

Duro Labs
PLM (Cloud)
🟢 Try Now

What It Does

Cloud-native Product Lifecycle Management (PLM) for hardware manufacturers — BOM management, revision control, supplier collaboration, manufacturing handoff.

Legacy Alternative

Arena PLM / Autodesk Vault / Siemens Teamcenter

Key Differentiator

Git-style branching for BOMs. Real-time supplier portal. Direct integration with Onshape, Fusion 360, Altium. BOM cost roll-up. No long-term contracts.

Pricing

Free tier. Team: $79/user/month. Business: custom. No long-term contracts.

Glazing Applicability

Medium — Useful for companies fabricating their own glazing units or storefronts. BOM for aluminum extrusions, glass types, gaskets, hardware.

🧪 MVP Trial (1 hour)

Sign up at durolabs.co (free). Create a BOM for a unitized glazed panel: mullions, glass lites, silicone, gaskets, anchors. Test revision branching.

Fabriq
MES / Shop Floor
🟢 Try Now

What It Does

Real-time manufacturing operations platform — production scheduling, machine monitoring, quality tracking, digital work instructions, and workforce management.

Legacy Alternative

Paper travelers + spreadsheets / legacy MES systems

Key Differentiator

Real-time machine connectivity via IoT/OPC-UA. Drag-and-drop scheduling. Digital work instructions with photos/video. Defect tracking with photo capture. Quick setup (days, not months). No dedicated IT team needed.

Pricing

~$30-80/user/month depending on modules. Free trial available.

Glazing Applicability

High — Track glass cutting, edgework, tempering, lamination in real time. Digital work instructions with visual QC criteria. Reduces rework at each station.

🧪 MVP Trial (half day)

Request trial at fabriq.io. Set up a simple production line: glass cutting → edge grinding → tempering → lamination. Create digital work instructions with tolerances.

AirWorks
Field Intelligence
🟡 Watch

What It Does

AI platform converts raw site data (drone imagery, 360° photos, LiDAR scans) into as-built 2D drawings, 3D models, and field reports automatically.

Legacy Alternative

Manual field measuring, total station surveys, hand-drawn as-builts

Key Differentiator

Upload drone flight data or 3D scans; get AutoCAD-compatible 2D drawings and 3D meshes. Field-to-BIM in hours, not weeks. Works with DJI, Skydio drones.

Pricing

$500-2,000 per project depending on area. Enterprise plans available.

Glazing Applicability

Medium — Generate accurate as-built facade conditions for retrofit glazing. Measure opening sizes, floor-to-floor heights from drone data. Most valuable for renovation work.

🧪 MVP Trial (demo)

Upload sample drone dataset from AirWorks. Request an as-built elevation drawing of a building facade. Compare accuracy to field measurements.

Bluebeam Cloud
PDF Collaboration
🟢 Try Now

What It Does

Cloud-based PDF collaboration and markup platform purpose-built for construction — measurement tools, annotation, revision comparison, and field-to-office collaboration.

Legacy Alternative

Paper markups, Adobe Acrobat, manual drawing distribution

Key Differentiator

Pricing

Revu Standard: $349/year. Revu CAD: $449/year. Revu eXtreme: $599/year. Cloud subscription: additional $25/user/month.

Glazing Applicability

High — Markup glazing elevations, measure glass square footage for estimates, count lites, compare drawing revisions. Cloud sync enables field tablet access.

🧪 MVP Trial (1 hour)

Download 14-day trial. Import a glazing elevation PDF. Use measurement tools to calculate glass area and count lites. Test cloud sharing with a colleague in real time.

BricsCAD
CAD/BIM (DWG)
🟢 Try Now

What It Does

Full DWG-native CAD platform with 2D drafting, 3D modeling, BIM, and Mechanical modules — all using native .dwg format with no conversion.

Legacy Alternative

AutoCAD / Revit — subscription-only, expensive

Key Differentiator

Native DWG (no file translation). BIM module for curtain wall modeling and interference checking. AI-powered auto-complete polylines. Perpetual license available — one-time purchase vs. Autodesk's subscription model. LISP/VBA/.NET API compatible.

Pricing

BricsCAD Lite: ~$850 (perpetual). Pro: ~$1,250. BIM: ~$2,500. Mechanical: ~$2,500. Subscription: ~$300-500/year optional.

Glazing Applicability

High — Native DWG for full AutoCAD compatibility. BIM module handles curtain wall modeling and material takeoffs. Perpetual license eliminates the annual Autodesk tax.

🧪 MVP Trial (2 hours)

Download 30-day free trial at bricsys.com. Import existing AutoCAD glazing details. Use BIM tools to model a curtain wall assembly. Compare DWG output compatibility.
